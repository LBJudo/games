⛏ Minicraft 3D

Clique pour jouer

ZQSD ou WA : se déplacer · Espace : sauter · Maj : courir

Souris : regarder · clic gauche : casser · clic droit : poser

1–9 ou molette : choisir le bloc · F : mode vol (Espace / Maj monter / descendre)

C : établi (outils, planches) · R : manger une pomme · G : mode créatif

🌊 Nage dans l'eau (Espace) · ⛏ Charbon : pioche en bois · Fer : pioche en pierre · 🍎 Les feuilles donnent des pommes · 💾 sauvegarde automatique

E : poser un bloc (si le clic droit ne marche pas) · tu commences avec 12 blocs de base

🧟 Des zombies apparaissent : clic gauche pour les frapper (3 coups). Une chute de plus de 3 blocs fait mal. La vie se régénère si on évite les coups.

⛏ Maintiens le clic gauche pour miner (la pierre est plus lente) · 🌞🌙 cycle jour/nuit : les zombies sont bien plus nombreux la nuit

Les blocs cassés vont dans ton inventaire (barre du bas) · clic droit pour les poser

Si la souris ne se verrouille pas : glisse la souris bouton enfoncé (ou flèches) pour tourner, clic simple = action

T : retour au point de départ (si tu es coincé) · 🌧 pluie et orages aléatoires
